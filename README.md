# مُسَابَقَة — لعبة مسابقات جماعية مباشرة (نظام الجرس)

لعبة مسابقات (Quiz/Buzzer) بنظام الوقت الحقيقي: المضيف يعرض السؤال على شاشة مشتركة،
واللاعبون يضغطون الجرس من جوالاتهم. **الواجهة عربية بالكامل (RTL)** بتصميم ناعم فاتح
(Vanilla / Beige) وخط **Tajawal**.

> **بدون رمز غرفة:** كل الأجهزة المتصلة تشترك تلقائياً في غرفة عالمية واحدة.

---

## 🚀 التشغيل

```bash
npm run install:all    # تثبيت اعتماديات السيرفر + الواجهة
npm run dev            # تشغيل السيرفر والواجهة معاً
```

| الصفحة | الرابط |
| --- | --- |
| شاشة البداية «من أنت؟» | http://localhost:5173/ |
| واجهة اللاعب (الجرس) | تُفتح تلقائياً بعد اختيار الاسم |
| لوحة المضيف | http://localhost:5173/host |

> 💡 للعب من الجوالات: افتح **نفس الرابط** على الجوال (نفس شبكة الواي فاي) باستخدام
> عنوان الشبكة المحلية المعروض في لوحة المضيف وسجلات السيرفر، مثال: `http://192.168.1.32:5173/`.
> وافق على تنبيه جدار الحماية على المنفذين `5173` و `3001`.

### للإنتاج
```bash
npm run build   # يبني الواجهة إلى client/dist
npm start       # يخدم الواجهة + Socket.io على منفذ 3001
```

## 🎮 آلية اللعب

1. عند فتح الموقع تظهر شاشة **«من أنت؟»** بأربعة أزرار: عبدالله طارق • محسن عصام • عبدالرحمن • عبدالله فايز.
2. يختار كل لاعب اسمه → تنتقل الواجهة إلى **الجرس**، ويظهر فوراً عند المضيف بحالة **«متصل»**.
3. المضيف (محمد) يدخل من الزر الصغير أسفل الشاشة **«دخول المضيف»**.
4. المضيف يضغط «ابدأ الجولة الأولى».

### 👀 العرض المتحكَّم به للسؤال (خطوة إلزامية)
- بعد كل ضغطة على **«السؤال التالي»** أو **«السابق»** يصبح السؤال **مخفياً**:
  - تظهر على كل الشاشات رسالة **«استعد للسؤال القادم…»** (نص السؤال لا يُرسل أصلاً من السيرفر قبل الكشف).
  - زر **«بدء المؤقت» يصبح معطّلاً**.
  - يظهر عند المضيف زر ضخم: **«👀 عرض السؤال للجميع»**.
- يضغط المضيف «عرض السؤال للجميع» → يظهر السؤال للجميع ويُفعَّل زر المؤقت.

### 🔔 الجولة
5. المضيف يضغط **«بدء المؤقت (٧ث)»**، واللاعبون يضغطون الجرس.
   - **أول من يضغط يقفل الباقين** → المؤقت يتوقف ويُبرز اسمه عند المضيف.
6. يحكم المضيف شفهياً (عبر Discord):
   - **صحيحة** → اللاعب يأخذ نقاطاً = **الثواني المتبقية**.
   - **خطأ** → يُستبعد من الجولة، والمؤقت **يعاود** للباقين.
7. عند وصول المؤقت للصفر → اهتزاز الشاشة وكشف الإجابة.

### اختصارات المضيف
| المفتاح | الوظيفة |
| --- | --- |
| `Space` | بدء الجولة / عرض السؤال / بدء المؤقت (حسب الحالة) |
| `1` | إجابة صحيحة |
| `2` | إجابة خاطئة |
| `N` / `←` | السؤال التالي |
| `R` | إظهار/إخفاء الإجابة |

## ⚙️ لوحة الإدارة (Admin Panel)

قسم قابل للفتح داخل لوحة المضيف:

1. **تعديل النقاط يدوياً** — زر `+1` و `−1` لكل لاعب من اللاعبين الأربعة (لا تنزل النقاط تحت الصفر).
2. **إعادة ضبط المؤقت** — يرجع المؤقت إلى ٧ ثوانٍ متوقفة.
3. **إعادة الجولة** — يفتح الأزرار (يلغي القفل والاستبعاد) ويعيد المؤقت.
4. **بدء مسابقة جديدة** — تصفير جميع النقاط والعودة للبداية.
5. **⚠️ تصفير اللعبة بالكامل** (زر أحمر في «منطقة الخطر») — يسأل تأكيداً ثم يمسح كل النقاط، يعيد للسباق من السؤال الأول، ويفتح الأزرار.

## 🎨 نظام التصميم (Soft & Light)

- الخلفية: `#FAF9F6` (عاجي دافئ) مع لمسات تدرّج ناعمة.
- البطاقات: `bg-white` • `rounded-2xl` • ظلال ناعمة دافئة (`shadow-soft` → `shadow-soft-lg`).
- النص: `text-stone-800` مع ثانوي `text-stone-400`.
- الألوان: عسلي (أزرار)، أخضر مريمي (صحيح)، مرجاني هادئ (خطأ)، سماوي (أدوات).
- الخط: **Tajawal** عالمياً.

## ✅ الموثوقية

- **السيرفر هو المرجع:** كل النقاط وحالات المؤقت تُحسب على السيرفر (لا غش من الواجهة).
- **مؤقت بمعيار زمني** (`endAt`) لا ينحرف مع تباطؤ الشبكة.
- **إعادة الاتصال:** تحديث الصفحة يحفظ هوية اللاعب ونقاطه؛ ودخول نفس الاسم من جهاز آخر يستبدل الجلسة القديمة.
- **CORS مفتوح** (`*`) ليعمل الاتصال من أي جهاز على الشبكة.
